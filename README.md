## 3. THE BTOC WEB APP
The repository ships **BTOC (Bio-Tactical Ontological Countermeasures)** — a React 19 + Vite + Tailwind CSS 4 application that presents the manuscript as an interactive console in the "Black Box" tactical style (Absolute Black, Safety Orange / Signal Blue / Positive Green accents, Inter + JetBrains Mono). Third system in the family, alongside BTNC (Breathwork) and BTRC (Sewa).

- **Distinctions** — the full manuscript as a reader; chapter bodies are code-split and load on demand from `src/content/`.
- **Installation Audit** — rate the integrity of each of the seven installed filters; computes render-engine status and routes the weakest filter to its distinction. Persists locally — nothing leaves the device.
- **Spectrum Console** — Polarity operationalized: locate your position on the activation, valence, or pendulum spectrum and receive the transmutation directive for that band.

```bash
npm install
npm run dev       # local development
npm run build     # type-check + production build to dist/
npm run preview   # serve the production build
```

`src/content/` mirrors `ebook-tactical/Post Edits/`; when chapters are revised, copy the updated files in so the app stays in sync.
